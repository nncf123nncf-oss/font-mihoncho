# フォント見本帳

自分の文章で、この端末に入っている書体を一斉に見比べる見本帳です。
チラシ・資料・スライドを自分で作る人が、フォントを勘ではなく見比べて選ぶための道具です。

## 使い方

1. ページを開く
2. 上の入力欄に、実際に使う予定の文章を入れる（例: 商品名・キャッチコピー・お知らせ文）
3. 20書体の見本が一斉にその文章に変わるので、見比べて選ぶ
4. 気に入った書体の「指定をコピー」を押すと、font-family 指定がコピーされる

## 収録書体（20種）

OS標準フォントのみ。Webフォントの読み込みはありません（外部通信ゼロ）。

- 日本語: 游ゴシック / 游明朝 / メイリオ / BIZ UDPゴシック / BIZ UDP明朝 / UD デジタル 教科書体 / MS Pゴシック / MS P明朝 / ヒラギノ角ゴシック / ヒラギノ明朝 / ヒラギノ丸ゴ / クレー / 筑紫A丸ゴシック
- 英数字向け: Segoe UI / Arial / Times New Roman / Georgia / Verdana / Courier New
- 汎用: system-ui（その端末の標準）

この端末に入っていない書体は、代わりの書体で表示されます（インストール判定はしていません）。
